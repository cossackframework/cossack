# Welcome to Cossack Docs

## Contents

Cossack is a modern, full-stack TypeScript framework designed for the edge computing and AI era.

## Key Features

- **Unified Syntax**: Write code once, run it on both server and client.
- **Real-time by Default**: Built-in support for WebSockets and Durable Objects.
- **Zero Configuration**: File-based routing and automatic bundling.

### Getting Started

To create a new Cossack app, run:

```bash {1}
npx cossack create my-app
```
