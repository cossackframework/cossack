# Welcome to Cossack Docs

## Contents

Cossack is a full-stack TypeScript framework for applications that run on edge platforms and Node.js.

## Key Features

- **Shared component model**: Write client and server methods in the same component.
- **Real-time updates**: Use WebSockets and Durable Objects.
- **File-based routing**: Create routes from files in the pages directory.

### Getting Started

To create a new Cossack app, run:

```bash {1}
npx cossack create my-app
```
